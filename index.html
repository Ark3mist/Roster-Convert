Accepts .xlsx / .xls / .csv, the Roster Report .pdf or saved web page .html, or the roster calendar .ics. Crew roster files become a daily roster; any other spreadsheet is converted as-is.
🔒 Your roster is private. It is never uploaded or saved.
  • Your file is opened and converted inside your own browser, on this device. It is not uploaded, sent, shared or stored on any server, and nobody else, including the owner of this site, can see it.
  • The page is locked by your browser so it cannot send data anywhere. It works even with your internet switched off once it has loaded.
  • The roster is held in memory only while the page is open. Refreshing or closing the page clears it. The PDF you download is saved only where you choose.
  • Only your settings are remembered in this browser: hidden columns, code descriptions, holiday edits, time mode, page size, and the name you typed for your staff number.
